# Surge 策略组图标集（本配置在用）

本仓库 `Surge.conf` 统一用 **[Koolson/Qure Color](https://github.com/Koolson/Qure)**：

```
https://raw.githubusercontent.com/Koolson/Qure/master/IconSet/Color/
```
